Analysis and data for Muckli project by Koen Seignette.

pre_post_dataSmall.mat
	Collected from 6 mice, the chronically matched data of naive (pre) and expert (post) sessions

pre_post_analysisSmall.m
	This script has code to plot that data. Recreating figure S7




pre_act_dataSmall.mat
	Collected from the same 6 mice, the chronically matched data of naive (pre) and task (active) sessions.
	Active sessions did not show the novel images, and show the stimulus 2 seconds instead of 1 second. As such have a different analysis script.
	
pre_act_analysisSmall.m
	This script has code to plot chronic-naive-task data. Recreating figure 2I
